# Slide 1: The Decision Before Us

- **Ask:** COO selects one AI pilot for next quarter.
- **Constraint:** Team capacity supports only one pilot — this is an either/or choice, not a sequencing question.
- **Budget ceiling:** $50,000 for the quarter.
- **Two candidates on the table:**
  - Option A — Internal knowledge search: $30,000
  - Option B — Automated customer credit decisions: $45,000
- **Recommendation:** Approve Option A.

---

# Slide 2: Why Option B Cannot Proceed Now

- **Legal approval is pending.** Production use is not authorized.
- Spending $45,000 on a pilot we cannot put into production risks consuming 90% of the quarterly ceiling with no deployable outcome.
- With only one pilot slot available, choosing B forfeits the quarter's capacity to an unresolved approval dependency.
- **Conclusion:** B is not actionable this quarter. It is not rejected on merit — it is blocked on authorization.

---

# Slide 3: Option A Is Ready to Execute

- **Scope:** Internal knowledge search pilot using approved internal policy documents — no new data authorization required.
- **Cost:** $30,000, leaving $20,000 of the $50,000 ceiling uncommitted.
- **Owner:** Dana (IT) — named accountability from day one.
- **Measurable success criteria already defined:**
  - Evaluate answer accuracy on 100 reviewed questions
  - Target: **≥ 90% accuracy**
- **Status:** No current result exists — this pilot generates the first real evidence base.
