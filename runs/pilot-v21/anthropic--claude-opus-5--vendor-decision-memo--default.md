# Decision Memo: Year-One Vendor Selection

**To:** CFO
**From:** Priya, Procurement Owner
**Re:** Vendor selection — Alpha vs. Beta
**Action requested:** Approval to proceed with Alpha

## Recommendation

Select **Alpha** for year one. Alpha is the only vendor that satisfies the mandatory SSO requirement while fitting inside the $100,000 year-one ceiling.

## Cost comparison

| Item | Alpha | Beta |
|---|---|---|
| Annual subscription | $72,000 | $60,000 |
| One-time setup | $20,000 | $10,000 |
| **Year-one total** | **$92,000** | **$70,000** |
| Budget headroom vs. $100,000 | $8,000 | $30,000 |

## Evaluation against constraints

**Budget ceiling ($100,000 incl. setup).** Both vendors comply. Alpha totals $92,000, leaving $8,000 of headroom. Beta totals $70,000, leaving $30,000.

**SSO mandatory before production.** Alpha provides the required SSO. Beta does not offer SSO and has given no committed delivery date. This is a disqualifying gap, not a timing risk we can schedule around: without a commitment date, we cannot forecast when Beta could reach production.

**Other requirements.** Both vendors meet all other stated requirements, so they do not differentiate the decision.

## Rationale

Beta's $22,000 year-one savings is real but unusable. Because SSO is mandatory before production and Beta has no committed delivery date, selecting Beta buys a subscription we cannot put into production on any known timeline. The cheaper option is only cheaper if it can be deployed.

Alpha clears the ceiling with $8,000 to spare. Note that Alpha's headroom is thinner, so any unbudgeted year-one additions should be flagged for review before commitment.
